# Regras de Execução — RSV360° Fases

## Regra Geral por Fase

Ao iniciar cada fase em conversa nova:

1. **Leia o prompt da fase**: `prompts/0[N]-[nome-fase].md`
2. **Leia as imagens de referência**: `referencias/fase-[N]/`
3. **Execute a fase conforme especificado no prompt**

Se o v0 não conseguir ler imagens direto do repo (fallback), o usuário anexa os arquivos manualmente.

## Workflow
```
Fase N (nova conversa):
├─ Prompt Mestre
├─ Prompt da Fase N
├─ Imagens de referência (do repo ou anexadas)
├─ Plan mode → aprovação
├─ Build → testes
├─ Commit → Merge para main
└─ Próxima fase (nova conversa)

Exceção: Fase 3 continua na mesma conversa da Fase 2
```
